# Visual assets

- `ink-landscape.png`: generated with the built-in image_gen tool for this app, 1536 × 1024. Prompt: a pale rice-paper UI background with low-saturation blue-green ink mountains and light gold autumn leaves, concentrated at the edges and lower quarter, leaving the center quiet; no text, people, logos or controls. The three user-provided images were style references, not copied game artwork.
- Icons: Phosphor Icons Core 2.1.1, regular weight, from the official npm distribution `@phosphor-icons/core`. See `PHOSPHOR-LICENSE.txt` for the MIT license. Symbol paths in `index.html` are from this library.
- Typography: system Songti / STSong for Chinese display text, with system sans-serif for compact operational labels. No proprietary reference fonts are redistributed.
